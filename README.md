# Thanks for vieiwing

This is a website for the Huntsville, Alabama local costume shop business MelodeeDesigns. This site would not be possible without the following projects:

### [Hugo Static Website Generator](https://gohugo.io/)

Hugo's fast build times and embedded web server allowed me to test changes immediately on my laptop. No guesswork required.

### [Blowfish Theme for Hugo](https://blowfish.page/)

Blowfish is one of the most popular themes for Hugo and it makes sense why. It has everything needed to build the exact website you are looking for. 
Additionally, the documentation for the theme is unmatched making it easy for anyone who can copy/paste to build with Blowfish.

## Site Structure

This website is built like a blog, but instead of adding new content to read, I add new images from costumes and shows.
As of right now, each show has it's own subfolder in /conent/gallery where all the Markdown files live to create the page.

All the images are store in /assets/img with the same subfolders. This allows Hugo to manage the image process and LazyLoading when building the website.

If you have any questions or suggestions, please let me know!
